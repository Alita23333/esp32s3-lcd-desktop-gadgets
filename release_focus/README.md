# 专注钟 — 发布包（独立固件）

番茄钟工作台：大字倒计时 + 物理按键 + **翻面暂停**（板载陀螺仪）+ **TF 卡专注记录**

## 文件
| 文件 | 用途 |
|---|---|
| `focus-timer-firmware.bin` | 合并固件（引导+分区+应用），刷入即用 |
| `flash_firmware.bat` | 一键刷固件（默认 COM5，可在文件顶部改） |

## 按键接线（3 颗轻触开关，无需电阻）
按键一端接引脚、另一端接 GND（板上任意 GND 均可，引脚已有内部上拉）：

| 引脚 | 功能 | 位置 |
|---|---|---|
| **GP11** | 开始 / 暂停 | 右侧排针，紧邻 GND |
| **GP10** | 待机：切换预设(25/45/5/15分) · 运行/暂停中：重置 | 右侧排针，GP11 旁 |
| **GP9** | 休息中：跳过休息 | 右侧排针，GP10 旁 |

没焊按键也能玩：用镊子短接"引脚↔GND"即可模拟按键。

## 功能
- **番茄流程**：专注 → 自动短休 5 分（每完成 4 个自动长休 15 分）→ 待机
- **翻面暂停**：倒计时中把屏幕翻朝下 = 暂停；翻回来 = 继续（板载 QMI8658 陀螺仪）
- **今日统计**：完成次数 + 累计分钟，NVS 掉电保存，跨天自动清零，屏幕画小番茄
- **TF 卡记录**：插卡后每次完成自动追加 `/focuslog.csv`（日期,时刻,分钟），长期专注数据
- **亮度**：固定 35%；LED 关闭；屏幕变化驱动刷新（无闪烁）；射频休眠（低温，电池友好）

## 串口命令（115200，可选）
`s` 开始/暂停 · `r` 重置/预设 · `t` 10 秒快速专注（验证流程）

## 排错
- 刷完屏幕全黑：重新插拔一次 USB（可能卡在下载模式没退出）
- 启动日志出现 SD 报错：未插 TF 卡，属正常；插卡后重启即生效
- 屏幕显示"已暂停"却不自知：可能刚翻过面——再翻回来即可恢复
