# 2048 体感版 — 发布包（独立固件）

经典数字合并游戏。4×4 棋盘、滑动合并，配板载陀螺仪 + 方向按键 + 串口三通道输入。

## 文件
| 文件 | 用途 |
|---|---|
| `game-2048-firmware.bin` | 合并固件（引导+分区+应用），刷入即用 |
| `flash_firmware.bat` | 一键刷固件（默认 COM5，可在文件顶部改） |

> 板子当前已运行此固件（2048 boot），可直接玩。

## 玩法
| 输入 | 作用 |
|---|---|
| 倾斜板子 | 控制滑动方向（开始游戏时自动标定中立姿态，需倾斜幅度较大才触发） |
| **GP11/GP10/GP9/GP8** | 上 / 下 / 左 / 右（四颗方向键） |
| 串口 `w`/`a`/`s`/`d` | 上/左/下/右移动 |
| 串口 `g` | 重新开局 |
| 串口 `p` | 遥测 `#B,分数,最高,结束,16格` |
| 游戏结束 | GP11 长按 1 秒重开 |

- 滑动后相同的数字合并翻倍并加计分；生成新块（90% 出现 2，10% 出现 4）
- 分数与**最高分 NVS 掉电保存**；合并到 2048 提示"到达 2048！继续？"
- 无路可走判定"游戏结束"

## 依赖
无需 WiFi，纯单机；陀螺仪（板载 QMI8658）用于倾斜操作。

## 排错
- 板子一动不动：开始游戏时放平板子（那一刻的姿态被标定为中立位）
- 刷完屏幕全黑：重新插拔一次 USB（可能卡在下载模式没退出）
