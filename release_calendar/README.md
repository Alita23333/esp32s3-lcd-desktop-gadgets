# 桌面日历固件 — 发布包

> 💡 需要日历 + GPU 监控二合一的固件（GP11 短接 GND 切换）？见 `../release_dual/`

## 文件
| 文件 | 用途 |
|---|---|
| `desktop-calendar-firmware.bin` | 纯日历合并固件（引导+分区+应用），刷入即用 |
| `flash_firmware.bat` | 一键刷固件（默认 COM5，可在文件顶部改） |

## 功能
完全独立运行，无需电脑配套程序：
- **时间**：NTP 自动同步（阿里云 NTP，UTC+8），上电联网即对时
- **定位**：IP 自动定位（显示区县名，免配置）
- **天气**：Open-Meteo 免密钥接口，每 20 分钟自动刷新
- **显示**：中文日期星期、大字时钟、天气图标、温度/湿度/风、今明预报
- **亮度自适应**：日出~日落高亮度，夜间自动降低（用真实日出日落时刻判断）
- **静默运行**：RGB 指示灯关闭；屏幕仅在时间/天气变化时局部刷新（无闪烁）

## 使用
1. 刷入固件（双击 `flash_firmware.bat`）
2. 板子上电 → 自动连 WiFi → 数秒内显示时间，约 10 秒后天气到位
3. 完事。日历界面右下角显示定位城市和最后同步时间

## 说明
- WiFi 配置在 `include/Config.h`（默认占位符），刷入前请填好你的 SSID/密码再编译
- 背光亮度：`Config.h` 的 `BACKLIGHT_DAY`（白天，当前 60）/ `BACKLIGHT_NIGHT`（夜间，当前 10）
- 天气刷新间隔：`WEATHER_OK_MS`（当前 20 分钟）
- 天气数据来自 open-meteo.com，定位来自 ip-api.com（均免费、无需注册）
- 若屏幕显示"天气需要网络"：检查路由器 2.4GHz 和联网状态

## 刷机排错
- 一直连不上串口：按住 BOOT 键再插 USB 线，然后重试
- 刷完屏幕全黑 / RGB 灯不亮：重新插拔一次 USB（可能卡在下载模式没退出）
