# WiFi 雷达扫描器 — 发布包（独立固件）

桌面射频侦察仪：雷达扫描动画 + 实时 WiFi 信号列表。**不连接任何 AP，纯侦测。**

## 文件
| 文件 | 用途 |
|---|---|
| `wifi-radar-firmware.bin` | 合并固件（引导+分区+应用），刷入即用 |
| `flash_firmware.bat` | 一键刷固件（默认 COM5，可在文件顶部改） |

## 功能
- **雷达动画**：30fps 扫描线旋转；附近网络按 SSID 哈希分布角度、按信号强度分布半径，
  扫描线扫过时亮点高亮
- **信号列表**：信号最强的 4 个网络（名称 + 信道 + RSSI + 信号条，按强度变色：
  绿 >-60 / 橙 >-75 / 红 更弱）
- 每 5 秒自动重新扫描；偶发空结果自动保留上一轮数据（不闪空屏）

## 串口命令（115200，可选）
`r` 强制重扫 · `p` 打印遥测（每网络一行 `#W,序号,SSID,RSSI,信道,加密`，结束行 `#WEND`）

## 用途场景
- 查看房间里的 WiFi 环境与信道占用（2.4G 拥挤诊断）
- 判断路由器是否在线（列表里消失 = 掉线）
- 桌面装饰性动态雷达（配合透明亚克力很有氛围感）

## 排错
- 刷完屏幕全黑：重新插拔一次 USB（可能卡在下载模式没退出）
- 显示"未发现网络"：正常环境下不可能，重试插拔；仍异常检查天线区域遮挡
