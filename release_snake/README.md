# 体感贪吃蛇 — 发布包（独立固件）

把板子当游戏手柄：**倾斜板子控制蛇的方向**（板载 QMI8658 陀螺仪），复古贪吃蛇。

## 文件
| 文件 | 用途 |
|---|---|
| `motion-snake-firmware.bin` | 合并固件（引导+分区+应用），刷入即用 |
| `flash_firmware.bat` | 一键刷固件（默认 COM5，可在文件顶部改） |

## 玩法
| 输入 | 作用 |
|---|---|
| **倾斜板子**（前后左右） | 控制蛇的方向（开始游戏时自动标定当前姿态为"中立位"） |
| **GP11**（紧邻 GND） | 开始 / 游戏结束后重开 |
| **GP10** | 暂停 / 继续 |
| 串口 `w`/`a`/`s`/`d` | 转向（替代输入，115200） |
| 串口 `g` | 开始/重开 |
| 串口 `p` | 打印遥测行 `#S,状态,得分,长度,头,食物,方向,加速度` |

- 吃到食物 +1 分、蛇身变长、移速渐增；撞墙或撞自己结束
- **最高分 NVS 掉电保存**，标题界面与结束界面都会显示
- 无需 WiFi，纯单机

## 排错
- 刷完屏幕全黑：重新插拔一次 USB（可能卡在下载模式没退出）
- 蛇自己乱动：开始游戏时尽量把板子放平——开始瞬间的姿态被标定为中立位
